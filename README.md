# GoFile Uploader
Recreation of [Script](https://github.com/Sushrut1101/GoFile-Upload) made by Sushrut1101 for uploading Files to https://gofile.io via Command Prompt 

## Usage
```bash
./upload.cmd <path/to/file>
```
You will get a link after the upload is complete.

## Features
- Upload Files to https://gofile.io Using their API
- No File Size Limit
- No Limit on Number of Files
- Fast Servers
- Free of Cost

## Requirements
- ```curl``` and ```jq``` needs to be installed.
